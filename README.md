# Student Stream Allocation System 🎓

A simple Java console application designed for **Class 9 computer science students** to understand conditional structures (`if-else-if` ladders) and user input using the `Scanner` class.

## 📌 Project Description
This program takes a student's name and total marks as input. Based on the marks entered, it automatically determines and prints the academic stream the student qualifies for.

### Stream Criteria:
* **300 or more marks:** Science Stream + Computer
* **200 to 299 marks:** Commerce Stream + Computer
* **75 to 199 marks:** Arts
* **Below 75 marks:** Try again

## 🛠️ Concepts Covered
* User Input using `java.util.Scanner`
* Variable initialization (`String`, `int`)
* Relational and Logical Operators (`>=`, `&&`, `<`)
* Conditional Control Structures (`if`, `else if`, `else`)

## 🚀 How to Run the Program

1. Make sure you have **JDK** installed on your system.
2. Clone this repository or download the `StreamAllocation.java` file.
3. Open your terminal or Command Prompt (or BlueJ/Eclipse/IntelliJ).
4. Compile the program:
   ```bash
   javac StreamAllocation.java
   ```
5. Run the program:
   ```bash
   java StreamAllocation
   ```
